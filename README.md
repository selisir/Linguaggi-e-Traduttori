# 📚 Linguaggi-e-Traduttori UniFe – Soluzioni Esercizi Haskell

Questo repository contiene le **soluzioni agli esercizi del corso _Linguaggi e Traduttori_** del  
**prof. Gavanelli – Università di Ferrara (UniFe)**.

Gli esercizi sono implementati in **Haskell** e organizzati in cartelle che seguono la struttura dei pacchi di slide del corso.

---

## 🎯 Obiettivo

Il repository ha lo scopo di:
- Fornire esempi pratici di **programmazione funzionale in Haskell**
- Supportare lo studio di:
  - Funzioni di ordine superiore
  - Liste e ricorsione
  - Pattern Matching
  - Lazy Evaluation
  - Tipi e classi
  - I/O

---
